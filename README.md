# CCA static web

Toto je statická HTML/CSS/JS verze webu.

## Co je v balíčku

- `index.html` – hlavní stránka
- `souteze.html` – seznam soutěží v ČR načítaný z veřejného WCA API
- `soutez.html?id=CompetitionId` – detail soutěže z WCA API
- `delegati.html` – statický seznam českých delegátů bez e-mailů
- `o-nas.html` – stránka o CCA
- `tym.html` – náš tým bez e-mailových adres

Odstraněno:

- články
- administrace
- list soutěžících
- moje skupiny / skupiny
- orga-dashboard
- přihlašování přes WCA
